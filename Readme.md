# Face Recognition Login 🔐

A simple face authentication system built using Python, OpenCV, and InsightFace.

## Features

- Face Registration
- Face Recognition
- Cosine Similarity Matching
- Real-time Webcam Detection
- Bounding Box Visualization

## Tech Stack

- Python
- OpenCV
- InsightFace
- NumPy
- ONNX Runtime

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python register.py
```

```bash
python face_login.py
```
